# 寻踪作品集网站自动搭建

给 **Claude / WorkBuddy 这类 agent** 用的技能包：一句话让 agent 给你做一个个人作品集网站，
带本地后台可以自己改，最后打包成一个能双击打开的 HTML。

- **版本**：正式版 1.0（2026-11-04）
- **作者**：寻踪踏迹
- **许可**：免费用于个人非商用；**商用、代客建站、转卖、打包进付费课程需书面授权**（见 `LICENSE`）
- **依赖**：Python 3.8+；`Pillow` 可选（缩略图 / 压图 / 摄影墙宽高比，没装会退化）。无 npm、无框架、无构建。

## 装

把整个 `xunzong-portfolio-website-autobuilder/` 文件夹放进技能目录（技术名用英文，避免 zip 分发/跨工具时中文文件名乱码；界面里显示的中文名是「寻踪作品集网站自动搭建」）：

```
~/.workbuddy/skills/xunzong-portfolio-website-autobuilder/      # 用户级，所有项目可用
<项目>/.workbuddy/skills/xunzong-portfolio-website-autobuilder/  # 项目级，只在这个项目里可用
```

放好后，对 agent 说一句「**用寻踪作品集网站自动搭建给我做个网站**」就会触发。
想先确认装好没有：说「**先建个 demo 站试试**」，它建完能打开就说明装好了。

## 用

**先看成品**：双击 `examples/demo-site/portfolio/index.html`（人物「陈屿」纯虚构）。

**做一个新的**：

```bash
python scripts/setup_site.py --out D:/我的作品集 --resume 简历.docx   # 从简历建
python scripts/setup_site.py --out D:/我的作品集 --demo              # 先看版式
```

建完会打印后台地址（`http://127.0.0.1:88xx`）。改完内容点「生成网页」，再打包：

```bash
python scripts/deploy_site.py --site D:/我的作品集 --pack ask
```

产物在 `_deploy/`：`站名-日期.html`（单文件，图全内联）或 `.zip`（要部署用）。

## 里面有什么

| 目录 | 内容 |
|---|---|
| `SKILL.md` | **agent 读这个**：六阶段流程、每步的完成判据与失败回退、后台全部操作 |
| `references/beginner-guide.md` | **人读这个**：新手教程（无命令、无键名） |
| `references/` | 数据结构全字段、设计令牌、75 条真实踩坑清单、自定义域名指引、网页爬取教程、流程图 |
| `scripts/` | 建站 / 生成 / 体检 / 打包 / 发布等 12 个脚本 |
| `assets/template/` | 站点骨架：生成器、样式表、后台、占位图 |
| `examples/` | 内置 Demo 站（约 14 MB，绝大部分是图片），双击就能看成品 |

## 规矩

- **不自动上线**：打包 ≠ 发布，到 `--push` 之前域名和仓库都不动。
- **不替你编内容**：简历里抽不到的字段留空，不猜。
- **占位图会说清**：哪几处还是假的会明确告诉你（`< 45KB` 的基本都是占位图）。
- **视频不白费劲**：默认只取视频首帧或同目录封面当封面图，不碰视频内容；除非你明确要。
