# 新手教程：第一次用，从这里看

> **这份文件是给人看的，不是给 agent 看的。**
> 第一次调用这个技能时，把下面「三十秒版」原样发给用户；他要是继续问，再展开后面几节。
> **不要把命令、文件名、`data.json` 甩给一个刚接触的人** —— 他不需要知道这些，只需要知道
> 「我要回答什么」「哪里要我亲手点」「卡住了找谁」。

---

## 三十秒版（先发这段）

> 一句话说清我们要做的事：**给你做一个个人作品集网站**，电脑上双击就能打开，
> 里面有你的作品图、论文、经历，能发给别人看，也可以挂到网上。
>
> 全程分六步，但**你只需要动手三处**：
> 1. 开始前回答我三个问题（给谁看 / 手头有什么素材 / 以后自己改不改）；
> 2. 中间打开一个网页，把文字改顺、图换掉（这个网页只有你电脑能开，别人看不到）；
> 3. 最后选一下：打包成哪种形式、要不要发布上线。
>
> 剩下的建站、排版、压图、打包，我来做。
> 建好以后你会拿到一个网页文件，双击就开；要发给别人，我再给你一个单文件版。
>
> 现在先回答第一个问题：**这个站主要是给谁看的？**（找工作 / 接活 / 自己存档 / 学校作业）

## 先看一个现成的样子（可选，30 秒）

不用等，也不用先准备素材：我可以直接打开一个**做好的样例站**给你看 ——
人物是虚构的（「陈屿」，学校、电话、邮箱全是假的），但版式、深浅色切换、图片放大、
手机上的效果都是真的。

看完你再说「就照这个样子做」或者「这里我想改」，比凭空描述快得多。
**样例站里的内容一个字都不会进你的站**，只用来确认风格。

## 要花多久、要不要花钱

| | |
|---|---|
| **建第一版** | 几分钟，取决于素材齐不齐。素材一次给完，基本一轮就好 |
| **改到满意** | 通常 2–3 轮。每轮你把「哪里不对」说具体一点，就能少一轮 |
| **花钱的地方** | **只有一处**：素材库里实在没有的画面要生成图片，按张算（5–10 信用点一张）。<br>**我会先报张数和总数，你同意才做** |
| **不花钱的做法** | 复用你已有的照片换一种取景框；或者先留占位图，明确告诉你哪几处还是假的 |

## 你只需要回答三个问题

问的时候一次问完，别挤牙膏。

| 问题 | 为什么问 | 答完决定什么 |
|---|---|---|
| **给谁看？** 找工作 / 接商单 / 自己存档 / 交作业 | 决定首页第一句写什么、联系方式放不放、作品挑哪几件 | 首屏文案、导航顺序、要不要联系页 |
| **手头有什么？** 简历、作品图、论文 PDF、奖项、旧主页链接 | 有就一次给完，省得来回补 | 有多少填多少，**没有也能先搭起来看版式** |
| **以后自己改吗？** 改一次就定 / 想随时改 | 决定要不要教你用后台 | 要改 → 教后台；不改 → 交付后给你说清怎么找我改 |

顺手多问一句：**有没有已经在用的旧主页或旧简历？** 有就发链接或文件，我去抓素材
（**只抓图和信息，文字会重写，不会照抄**）。

**素材怎么给我**：直接拖进对话就行 —— 照片、PDF、docx、txt 都认。
**不用先整理、不用改文件名、不用按顺序**，我按内容自己分。一次性全给，比一批一批给快得多。
**视频不用发原片**（又大又慢）：发一张封面图就行；真发了原片，我们也只取第一帧当封面，
不会去处理视频本身 —— 视频本身在网站上就是一个链接。

- **三个都答完**才算这一步走完；有任何一个含糊，先问清再动手。
- 答「我也不知道给谁看」是正常的 —— 那就先做一版通用的，看到实物再调，比空想快。

## 六步里，你和我各干什么

| 步 | 我做什么 | 你要做什么 |
|---|---|---|
| **① 确认三件事** | 问你上面那三个问题，看素材够不够 | 回答问题，把素材发我 |
| **② 建站** | 在你电脑上建好文件夹、生成第一版网页、把后台打开 | **什么都不用做**，等一两分钟 |
| **③ 改内容** | 把你的素材填进去，按你说的改文案、调顺序 | 打开预览看，告诉我「这里不对」「这张换掉」 |
| **④ 补图片** | 找图、换框复用、必要时生成；哪几处还是假图我会点名 | 认可，或者把你的原图发我替换 |
| **⑤ 打包** | 打包成一个文件或压缩包 | 选一种：**发给别人看** / **要传上网** |
| **⑥ 上线**（可选） | 备好能上传的目录，把步骤一条条打给你 | 最省事的是我在对话里直接帮你发布；GitHub 那几步**只能你自己点**（要你的账号） |

一句话记住：**①你答、②我干、③你看着说、④我补、⑤你选、⑥你授权。**

## 后台是什么（唯一需要你亲手操作的东西）

### 它长什么样

一个**在你浏览器里打开的网页**，不是软件，不用安装。

- **左边一列导航**（窗口窄的时候收成顶部一排页签），顶上有个「找页面」的小框，输关键词就过滤。分两组：
  - **站点** —— 前三个是固定的：
    - **总设置** —— 全站共用：站名、你的名字、网页标题、首页那句话、顶栏 logo、头像、
      右上角按钮文字、页脚那行、**配色**（6 套预设 + 自己取色）、深浅色规则、收藏夹图标、
      **历史版本**。
    - **页面设置** —— 加页、删页、调顺序、显示还是隐藏。新建页面**先选模板再起名**。
    - **封面** —— 首屏那一屏单独管。
  - **内容页面** —— **每一项对应你网站上的一个页面**（影像、摄影、图文、论文、随笔、关于我……），
    点哪个改哪一屏：放什么、每条内容的图 / 标题 / 说明 / 链接。
- **右上角四个按钮**：打开预览、**生成网页**、补缩略图、保存（按 Ctrl+S 也行）。

### 三条规矩（记这三条就够）

1. **改完必须点「生成网页」。** 不点，预览永远是旧的 —— 九成的「怎么没变」都是这个。
   ⚠️ **只点「保存」不够**：保存只把内容存下来，网页还是旧的。点「生成网页」时会顺带保存，
   所以**平时只点右边那个蓝色按钮就行**。
2. **它只在你电脑上开着。** 地址是 `127.0.0.1` 开头的一串数字，别人打不开，也不影响你上网。
   关掉那个黑色窗口（一个全是字的黑框），后台就关了，网站文件还在。
3. **改坏了不用怕。** 「总设置」最下面有「历史版本」，每次保存都留一份快照，
   点一个时间点就能退回去。

### 下次怎么再打开

- **只想看看网站**：双击站点文件夹里的 **`打开网站`**（Windows 上带 .bat 后缀，Mac 上是 .command）。
  不用开后台，看完关掉就行。
- **想改内容**：双击 **`打开后台`**（或 `admin/` 里的 `start-admin.bat` / Mac 的 `start-admin.command`），
  黑窗口里会出现中文提示，浏览器会自己弹出来。关掉那个黑窗口，后台就停了。

这两个「打开…」是**第一次生成网页时自动放好的**，就在站点文件夹最外层。
找不到的话，在文件夹里搜「打开」。黑窗口里的提示都是中文，看着不对劲就把截图发我。
Mac 上第一次双击如果没反应，跟我说一声，我来处理。

## 最容易卡住的六件事

| 你遇到的 | 真实原因 | 怎么办 |
|---|---|---|
| 改了内容，预览没变 | 只点了「保存」，或者两个都没点 | 点右上角**「生成网页」**，再刷新预览 |
| 后台打不开 / 一片白 | 端口被别的程序占了，黑窗口被关了，或者我这边的会话已经结束（服务会跟着停） | 重新双击「打开后台」；还不行找我，我换个端口重启 |
| 图片显示不出来 | 图没放进网站的图片文件夹，或文件名带空格和奇怪符号 | 把图发我，我来放 |
| 手机上导航挤成一条 | 正常设计：窄屏时导航整排横滑 | 不用改 |
| 想再加一个页面 | 最多 10 页，删页不删内容 | 告诉我加哪种，我带你选模板 |
| 想要一个现有模板里没有的版式 | 10 种模板覆盖常见需求，但不是全部 | 说清要什么效果，我看看能不能加 |

## 最后你手里会有什么

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `portfolio/index.html` | 你的网站 | **双击就打开**，图片走旁边的文件夹 |
| `打开网站` | 双击看网站的快捷方式 | 不用开后台，看完关掉 |
| `打开后台` | 双击开后台的快捷方式 | 想改内容时用，等于 `admin/` 里的启动脚本 |
| `_deploy/站名-日期.html` | 单文件版，图全塞进去了 | 发微信、发邮件、传网盘，对方双击就开，不会丢图 |
| `_deploy/站名-日期.zip` | 压缩包 | 要传到网上用这个：最省事是我在对话里直接帮你发布；也可以上 GitHub（网页拖文件就行）/ Netlify / 自己服务器 |
| `admin/` | 后台 | 想自己改内容时双击里面的 `start-admin.bat`（Mac 是 `start-admin.command`） |

**交付前我会先自己打开一遍**再发你 —— 单文件尤其要试，图没塞进去在电脑上看着是好的。

**想用自己的域名**（`www.你自己的名字.com` 这种）也有一步一步的图文指引，跟我说一声就行，
全程不用你懂技术。

## 四个词，听懂就行

- **后台**：只有你能打开的一个网页，用来改网站内容。
- **生成网页**：把后台里改的东西真正写进 `index.html` 的那个按钮。
- **单文件**：图片全部塞进一个 HTML。发给别人不怕丢图，但改内容要重新打包。
- **占位图**：暂时顶替真图的假图（灰底、色块、程序画的）。我会明确告诉你哪几处还是它。
